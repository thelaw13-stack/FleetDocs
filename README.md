# FleetDocs

Canonical source of truth for fleet Build Sheet standards and asset records.

## North star

A Build Sheet is the authoritative, 30-second dashboard answering: **What is this asset today?** It is supported by separate history, technical specification, service, parts, and photo records.

## Authority order

1. `GOVERNANCE.md`
2. `standards/build-sheet-schema.md`
3. `standards/population-standard.md`
4. Companion-document standards
5. Templates
6. Individual fleet records

Agents must populate the current templates without redesigning them. Proposed schema changes and population-rule improvements are separate changes.

## Versions

- Governance: 1.0
- Canonical Build Sheet Schema: 2.0
- Population Standard: 1.0

## Repository map

- `standards/` — controlled definitions and rules
- `templates/` — copyable blank records
- `fleet/` — one directory per asset
- `CHANGELOG.md` — version history

The first canonical asset is `fleet/1970-vw-baja/`.
